# htd-website

This repository contains custom HTML, CSS, and JavaScript code snippets and sections developed for the **Highway to Destiny** non-profit organization website. 

The purpose of this project is to store and back up custom web components used to enhance the organization's online presence.

## 📂 Project Structure

Each directory represents a specific section or campaign on the website:

* **`CommunityPartners/`** – Code and text assets for showcasing community organization partnerships.
* **`Donate/`** – Donation page variants, including integration layouts for platforms like Zeffy.
* **`DonorWall/`** – Visual layout displaying and honoring individual donors.
* **`Fundraisers/`** – Special event landing pages and promotional code (e.g., Valentine's Day Raffle).
* **`GiveSTLDay/`** – Custom HTML structures built for the annual Give STL Day regional fundraising event.
* **`ImpactBanner/`** – Highlight banners showcasing organizational metrics.
* **`Merch/`** – Promotional sections for the official Bonfire apparel store.
* **`News&Events/`** – Layouts for sharing upcoming events.
* **`Newsletter/`** – A custom newsletter template.

*Note: Files appended with dates (e.g., `*-04072026.html`) or `-og` represent historical versions or structural backups from specific deployment days.*

## 🚀 How to Use These Files

1. **Locate the Section**: Browse to the folder matching the feature you want to update or review.
2. **Review Code**: Open the `.html` or `.txt` files to view the underlying markup and embedded CSS styles.
3. **Deploy**: Copy the required code blocks directly into the content management system (CMS) running the Highway to Destiny website.
